# 环形数组（Circular Array / Ring Buffer）

参考文档：
- labuladong：https://labuladong.online/zh/algo/data-structure-basic/cycle-array/

## 一句话本质

环形数组通过**两个指针 + 取模运算**，在 **O(1)** 时间内增删**头部/尾部**元素。

## 核心思想

普通数组的问题：在头部删除元素，为保持连续，后面所有元素都要**前移一位**（O(n)）。

删除前：

| 索引 | 0 | 1 | 2 | 3 |
|:--:|:--:|:--:|:--:|:--:|
| 值 | A | B | C | D |

删除头部 A 后（B、C、D 全部前移一位，物理上真的搬了数据）：

| 索引 | 0 | 1 | 2 | 3 |
|:--:|:--:|:--:|:--:|:--:|
| 值 | B | C | D | · |

环形数组的解法是——**不移动元素，而是移动「头部」的定义**。用一个 `start` 指针记录「现在的头在哪」，删头部只需让 `start` 前进一格，数据原地不动：

删除前（`start` 指向索引 0）：

| 索引 | 0 | 1 | 2 | 3 |
|:--:|:--:|:--:|:--:|:--:|
| 值 | A | B | C | D |
| 指针 | ↑`start` |  |  | `end`→（越界回绕到 0） |

删除头部 A 后（只把 `start` 从 0 移到 1，A 所在格作废，无任何数据搬移）：

| 索引 | 0 | 1 | 2 | 3 |
|:--:|:--:|:--:|:--:|:--:|
| 值 | · | B | C | D |
| 指针 |  | ↑`start` |  | `end`→（越界回绕到 0） |

当指针走到数组末尾还要继续前进时，用**取模运算**让它「绕回」开头，数组在逻辑上就成了一个首尾相接的环：

```
下一个位置 = (当前位置 + 1) % 容量
```

例如容量为 4、`end` 在索引 3 时插入下一个元素，`end` 会回绕到索引 0：

| 当前 end | 计算 | 新 end |
|:--:|:--:|:--:|
| 3 | `(3 + 1) % 4` | 0 |
| 0 | `(0 + 1) % 4` | 1 |

> 「环形」不是物理上的，内存里数组仍是线性的；环形只是取模带来的**逻辑**访问效果。

## 关键设计

- `arr`：底层数组，容量固定。
- `start`：指向**第一个有效元素**。
- `end`：指向**最后一个有效元素的下一格**（即下一个要写入的空位）。
- `size`：当前元素个数。

区间采用**左闭右开 `[start, end)`**：
- `start === end` 时区间为空，初始化 `start = end = 0` 天然表示空数组，边界处理最简单。

**空/满判断**用 `size` 最直观：`size === 0` 为空，`size === capacity` 为满（无需牺牲存储位）。

## JavaScript 实现

```js
class CircularArray {
  constructor(capacity = 8) {
    this.arr = new Array(capacity);
    this.start = 0; // 第一个有效元素
    this.end = 0;   // 最后一个有效元素的下一格
    this.size = 0;
  }

  // 环形地取下一个/上一个索引（+capacity 是为了避免负数取模）
  _next(i) { return (i + 1) % this.arr.length; }
  _prev(i) { return (i - 1 + this.arr.length) % this.arr.length; }

  isEmpty() { return this.size === 0; }
  isFull()  { return this.size === this.arr.length; }

  // 头部插入：start 先后退一格，再写入
  addFirst(val) {
    if (this.isFull()) throw new Error('数组已满');
    this.start = this._prev(this.start);
    this.arr[this.start] = val;
    this.size++;
  }

  // 尾部插入：写入 end，再前进一格
  addLast(val) {
    if (this.isFull()) throw new Error('数组已满');
    this.arr[this.end] = val;
    this.end = this._next(this.end);
    this.size++;
  }

  // 删除头部：读出 start，start 前进一格
  removeFirst() {
    if (this.isEmpty()) throw new Error('数组为空');
    const val = this.arr[this.start];
    this.arr[this.start] = undefined; // 释放引用，帮助 GC
    this.start = this._next(this.start);
    this.size--;
    return val;
  }

  // 删除尾部：end 后退一格，读出该位置
  removeLast() {
    if (this.isEmpty()) throw new Error('数组为空');
    this.end = this._prev(this.end);
    const val = this.arr[this.end];
    this.arr[this.end] = undefined;
    this.size--;
    return val;
  }

  // 随机访问：逻辑第 i 个 → 物理索引，仍是 O(1)
  get(i) {
    if (i < 0 || i >= this.size) throw new Error('越界');
    return this.arr[(this.start + i) % this.arr.length];
  }
}
```

使用示例：

```js
const ca = new CircularArray(4);
ca.addLast(1);    // [1]
ca.addLast(2);    // [1, 2]
ca.addFirst(0);   // [0, 1, 2]
ca.removeLast();  // 移除 2 → [0, 1]
ca.get(0);        // 0
```

## ⚠️ JavaScript 取模的坑

JS 里 `%` 对负数返回负值：`-1 % 5 === -1`（Python 才是 `4`）。所以指针后退时**必须先加容量再取模**：

```js
// ❌ 错误：可能得到负索引
prev = (i - 1) % n;
// ✅ 正确
prev = (i - 1 + n) % n;
```

上面 `_prev` 已经这样处理了。

## 复杂度

| 操作 | 环形数组 | 普通数组 |
|---|---|---|
| 头部增删 `addFirst / removeFirst` | **O(1)** | O(n) |
| 尾部增删 `addLast / removeLast` | O(1) | O(1) |
| 随机访问 `get(i)` | O(1) | O(1) |
| 指定位置增删 | O(n) | O(n) |

环形数组只在**头部增删**上把 O(n) 优化成了 O(1)，中间位置增删仍需搬移元素。

## 应用场景

- **队列 / 双端队列**：固定容量队列用它实现，入队出队都是 O(1)。
- **环形缓冲区（Ring Buffer）**：日志缓存、音视频流、传感器最近 N 条数据——满了就覆盖最旧的。
- **轮询（Round-Robin）**：负载均衡轮流选服务器、动画循环切换颜色，`idx = (idx + 1) % n`。

## 小结

- 本质：**两个指针 + 取模**，O(1) 增删头尾。
- 核心：不搬元素，只移动「头/尾」的定义。
- 记牢：左闭右开 `[start, end)`、`size` 判空满、JS 取模负数要 `(i - 1 + n) % n`。
