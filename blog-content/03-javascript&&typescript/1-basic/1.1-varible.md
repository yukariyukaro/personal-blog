## 面试题目：var、let、const的区别
| 特性 | var | let | const |
|------|-----|-----|-------|
| 作用域 | 函数作用域/全局作用域 | 块级作用域 | 块级作用域 |
| 变量提升 | ✅ 提升（声明前访问为undefined） | ❌ 暂时性死区（TDZ） | ❌ 暂时性死区（TDZ） |
| 重复声明 | ✅ 允许 | ❌ 不允许 | ❌ 不允许 |
| 重新赋值 | ✅ 允许 | ✅ 允许 | ❌ 不允许 |
| 必须初始化 | ❌ 不需要 | ❌ 不需要 | ✅ 必须 |
| 全局对象属性 | ✅ 是（如window） | ❌ 不是 | ❌ 不是 |
详细说明
作用域
var：函数作用域（在函数内声明的变量，只在该函数内可见）
let/const：块级作用域（在{}内声明的变量，只在该代码块内可见）
```javascript
// var 示例
function exampleVar() {
  if (true) {
    var x = 10;
  }
  console.log(x); // 10（var无视块级作用域）
}

// let/const 示例
function exampleLet() {
  if (true) {
    let y = 20;
  }
  console.log(y); // ReferenceError
}
console.log(a); // undefined
var a = 5;
let/const：不存在提升，存在暂时性死区（TDZ）
```
