 ## 2.2 我们怎样创建一个对象？
- 字面量方式
- 构造函数方式
举例：
```js
// 字面量方式
const obj1 = {
  name: 'obj1',
  age: 18,
}
// 构造函数方式
function Obj2(name, age) {
  this.name = name
  this.age = age
}
const obj2 = new Obj2('obj2', 18)
```
这两种方式都会在堆内存中创建一个新的对象，并将对象的引用赋值给变量。
## 2.3 引用类型与浅拷贝
引用类型：详见[数据类型](1.2-data-type.md)
浅拷贝：创建一个新的对象，将原对象的属性值复制到新对象中。如果属性值是引用类型，那么新对象的属性值和原对象的属性值指向的是同一个内存地址。
也就是说：浅拷贝不在堆中创建新的对象。
## 2.4 深拷贝
深拷贝：创建一个新的对象，将原对象的属性值复制到新对象中。如果属性值是引用类型，那么新对象的属性值和原对象的属性值指向的是不同的内存地址。
