# 构建工具简介
## 定义：
**构建工具**是前端开发中负责把源代码和资源（JavaScript、TypeScript、CSS、图片、模板等）转换为可在浏览器或生产环境中高效运行的产物的一类工具。它们通常负责**模块打包、依赖解析、代码转换（如 Babel/TypeScript）、资源优化（压缩、Tree Shaking）、以及开发时的热更新/本地服务器**等功能。 
### 例子：
已知，浏览器只认识html、css、javascript。
而企业级项目需要以下功能：
- 1.typescript： 需要tsc将typescript转换为javascript
- 2.css预处理器： 如sass、less等，需要将其转换为css
- 3. React/Vue: 将.jsx、.vue文件转换为javascript
- 4. 体积优化： 压缩代码、合并文件、移除未使用代码（Tree Shaking）等
我们希望：我们只管写代码，构建工具帮我们处理这些复杂的任务。
当然：构建工具做的事情不只这些。
打包： 将我们写的浏览器不认识的代码变为浏览器认识的代码。
### 核心职责（常见功能）
- **模块化开发支持**：支持直接从node_modules中引入模块+多种模块化支持
 - 比如说：我们写 import _ from 'lodash'，如果直接在浏览器中运行，会报错：Relative references must start with either "/", "./", or "../"，
 - 这是因为：浏览器不认识node_modules中的模块.
- **转译与预处理**：把现代语法或非 JS 资源（TS、JSX、Sass、Less）转成浏览器能识别的格式。  
- **代码分割与懒加载**：按需加载代码，减少首屏体积。  
- **优化与压缩**：压缩 JS/CSS、移除未使用代码（Tree Shaking）、资源指纹化。  
- **开发体验**：构建工具自动监听文件变化，当文件变化后自动调用对应集成工具重新打包。
