# HTML 简介

## HTML 是什么

HTML，全称是 **HyperText Markup Language**，中文通常叫 **超文本标记语言**。

它不是编程语言，因为它不负责计算逻辑，也不负责处理数据。HTML 的核心作用是：**用标签描述网页内容的结构和语义**。

在浏览器中，一个网页通常由三部分组成：

| 技术 | 作用 | 类比 |
|------|------|------|
| HTML | 描述内容结构 | 骨架 |
| CSS | 控制视觉样式 | 外观 |
| JavaScript | 处理交互逻辑 | 行为 |

例如，一个商品详情页中：

| 页面内容 | HTML 负责表达 |
|----------|----------------|
| 商品标题 | 这是一个标题 |
| 商品图片 | 这里有一张图片 |
| 商品价格 | 这里是一段价格信息 |
| 购买按钮 | 这里有一个可点击按钮 |

至于标题是什么颜色、图片多大、按钮点击后发生什么，这些分别由 CSS 和 JavaScript 继续处理。

## 为什么需要 HTML

浏览器拿到一份 HTML 文档后，会解析其中的标签，构建出页面结构，再把内容显示出来。

所以，HTML 解决的是一个最基础的问题：

> 如何让浏览器知道“这段内容是什么”。

没有 HTML，浏览器只能看到一堆文本；有了 HTML，浏览器就能知道：

| 内容 | 语义 |
|------|------|
| `h1` | 一级标题 |
| `p` | 段落 |
| `a` | 链接 |
| `img` | 图片 |
| `ul` / `li` | 列表 |
| `button` | 按钮 |

这也是 HTML 最重要的学习重点：**不是死记所有标签，而是理解标签在表达什么语义**。

## HTML 最核心的语法

HTML 的基本单位是 **元素**。一个元素通常由开始标签、内容和结束标签组成。

```html
<p>这是一段文字</p>
```

| 部分 | 示例 | 说明 |
|------|------|------|
| 开始标签 | `<p>` | 表示元素开始 |
| 内容 | `这是一段文字` | 页面中要展示的内容 |
| 结束标签 | `</p>` | 表示元素结束 |

### 1. 标签

标签用来标记内容的类型。

```html
<h1>HTML 简介</h1>
<p>HTML 用来描述网页内容结构。</p>
```

这里的 `h1` 表示一级标题，`p` 表示段落。

### 2. 属性

属性用来给标签补充信息，通常写在开始标签中。

```html
<a href="https://developer.mozilla.org/zh-CN/docs/Web/HTML">学习 HTML</a>
<img src="./logo.png" alt="网站 Logo">
```

| 属性 | 作用 |
|------|------|
| `href` | 描述链接跳转地址 |
| `src` | 描述资源地址 |
| `alt` | 描述图片无法显示时的替代文本 |

### 3. 嵌套

HTML 元素可以嵌套，用来表达内容之间的层级关系。

```html
<article>
  <h1>前端是什么</h1>
  <p>前端负责把数据和功能展示给用户。</p>
</article>
```

嵌套时要注意：**先打开的标签，最后关闭**。

```html
<!-- 正确 -->
<p>学习 <strong>HTML</strong></p>

<!-- 错误 -->
<p>学习 <strong>HTML</p></strong>
```

### 4. 空元素

有些标签没有包裹内容，只通过属性表达信息，这类元素通常叫空元素。

```html
<img src="./photo.png" alt="示例图片">
<input type="text" placeholder="请输入用户名">
<br>
```

常见空元素包括 `img`、`input`、`br`、`meta`、`link` 等。

## 一个最小 HTML 页面

一份完整 HTML 文档通常长这样：

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>你好，HTML</h1>
    <p>这是我的第一个网页。</p>
  </body>
</html>
```

| 结构 | 作用 |
|------|------|
| `<!doctype html>` | 告诉浏览器按现代 HTML 标准解析 |
| `html` | 整个 HTML 文档的根元素 |
| `head` | 放页面配置，不直接展示在页面主体中 |
| `meta charset="UTF-8"` | 设置字符编码，避免中文乱码 |
| `title` | 浏览器标签页标题 |
| `body` | 页面真正展示给用户的内容 |

## 学习 HTML 应该关注什么

AI 时代不需要把所有标签和属性都背下来。更重要的是掌握三个判断：

| 问题 | 判断方式 |
|------|----------|
| 这段内容是什么？ | 选择语义合适的标签 |
| 内容之间是什么关系？ | 用嵌套表达层级 |
| 浏览器还需要什么信息？ | 用属性补充地址、类型、说明等 |

HTML 的核心并不复杂：

> HTML = 用标签给内容做结构化标记。

后续学习 CSS 和 JavaScript 时，可以把 HTML 理解为页面的“稳定结构”：CSS 在这个结构上加样式，JavaScript 在这个结构上加交互。
